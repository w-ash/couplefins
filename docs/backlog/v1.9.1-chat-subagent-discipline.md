Status: Planned
Effort: S

## Goal

Two backports from mixd v0.9.2/v0.9.4:

1. **Progressive disclosure for the subagent.** `build_subagent_tools()`
   currently loads all 15 read tools un-deferred into a low-effort model —
   exactly where tool bloat hurts selection most. Give it the same
   discipline as the main loop: a curated hot set, the rest deferred behind
   tool search.
2. **Summary re-wrap.** `run_subagent` returns its summary unwrapped — the
   documented "accepted residual" in `user_data.py`. The summary is built
   from library text whose injection markers the subagent was told to keep;
   without re-wrapping, an injected instruction would launder into the
   write-capable main model. Wrap the whole payload (truncation prefix
   included) with `user_data.wrap()`, which also neutralizes embedded tag
   literals.

## Known acceptable gap

Couplefins' adapter deliberately hides tool-search lifecycle events, and the
subagent's answer-buffer drain only clears on dispatched-tool starts —
narration preceding a subagent tool_search call can leak into the summary.
Acceptable: it is wrapped data now. Do not widen the adapter event surface
for this.
