### v0.11.0: Auth Backend
**Goal**: Add name+password authentication with JWT httpOnly cookies to the FastAPI backend.
**Context**: Identity is currently localStorage-based — anyone who opens the URL has full access. With v1.0.0 targeting Neon DB for multi-device access, server-verified identity is a prerequisite. The auth system is deliberately simple: name + password, no email infrastructure, no OAuth. Proportional to a 2-user personal tool.
**What this unlocks**: Server-verified identity, session persistence via httpOnly cookies, protected API endpoints. Foundation for v0.11.1 (frontend login) and v1.0.0 (multi-device via Neon DB).
**Key tech choices**: `argon2-cffi` for password hashing (argon2id, OWASP recommended). `PyJWT` for JWT tokens. httpOnly cookies with SameSite=Lax. Constructor injection for auth infrastructure in use cases.

- [x] **Person entity: add `password_hash`**
    - Effort: S
    - What: Add `password_hash: str = ""` to the Person entity. Empty string means no password set (migration state).

- [x] **Auth domain module**
    - Effort: S

#### Infrastructure

### v0.11.2: Personal Budget Backend
**Goal**: Per-person budget limits and per-person spending computation alongside existing household budgets.
**Context**: Currently one budget per category group covering household spending. Each person wants to also track their total spending (their share of shared expenses + their personal purchases) against a personal limit. The household budget and personal budget are independent — different amounts, different spending calculations.
**What this unlocks**: Backend support for the "My Budget" scope toggle (v0.11.3). Per-person spending computation. Transaction scope filtering.
**Key tech choices**: `person_id: UUID | None` on CategoryGroupBudget (None = household). New `compute_personal_budget_overview()` domain function. Transaction scope query parameter.

- [x] **Budget entity + migration**
    - Effort: S
    - What: Add `person_id: UUID | None = None` to `CategoryGroupBudget` entity. Alembic migration adding nullable `person_id` FK column. Update unique constraint to `(group_id, effective_from, person_id)`. Update repository conversions and add `get_by_person()` method.

- [x] **Per-person spending computation**
    - Effort: M
    - Dependencies: "Budget entity + migration"
    - What: Add `_compute_person_share(tx, person_id) -> Decimal` to `budget.py` — computes what one person owes for a transaction based on who paid and `payer_percentage`. Add `compute_personal_budget_overview()` — filters budgets by person_id, computes spending as person's share of household transactions + their personal (non-household) transactions. Add `shared_spending` and `personal_spending` breakdown to group status.
    - Notes: Reuse `compute_shares()` from `splits.py` where possible. At ~200 txns/month, full-scan computation is fine.

- [x] **Budget + reconciliation API scope**
    - Effort: M
    - Dependencies: "Per-person spending computation"
    - What: Add `scope` and `person_id` query params to `GET /budgets/overview`. Add `person_id` to `POST /budgets`. Add `scope` param to reconciliation endpoint: `household` (default), `personal` (this person's non-household only), `all` (household + this person's personal). Update schemas with `person_id`, `shared_spending`, `personal_spending` fields.

### v0.11.3: Scope UI
**Goal**: Frontend scope toggles for budgets and transactions.
**Context**: The backend now supports personal budget computation and transaction scope filtering (v0.11.2). The frontend needs scope toggle controls and personal budget management UI.
**What this unlocks**: Each person can see and manage their personal budget alongside the household budget. Transaction browsing scoped to household, personal, or all.

- [x] **Budget scope toggle + personal budget management**
    - Effort: L
    - Dependencies: v0.11.2
    - What: Add `[Household | My Budget]` segmented control to BudgetPage alongside existing `[Monthly | YTD]`. "Household" shows couple's total spending vs household budget (current behavior). "My Budget" shows personal spending (shared portion + personal portion) vs personal budget, with sub-line per group: `(shared: $180 · personal: $100)`. Personal budget management: set/edit/delete personal limits in "My Budget" mode.

- [x] **Transaction scope filter**
    - Effort: M
    - Dependencies: v0.11.2
    - What: Add `[Household | Personal | All]` scope filter to TransactionsPage filter bar. "Household" = all household transactions from both people (current behavior). "Personal" = only logged-in user's non-household transactions. "All" = household + logged-in user's personal. Persist scope in URL search params.
