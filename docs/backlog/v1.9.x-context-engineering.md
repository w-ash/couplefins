# v1.9.x — Context Engineering (Series Overview)

The v1.9.x series backports the context-engineering delta from mixd's chat
harness. mixd's chat stack was ported *from* couplefins v1.8.x (its v0.9.x
series), then grew four features on top during 2026-07; this series brings
them home. The governing idea, per Anthropic's context-engineering guidance:
the model should see the smallest high-signal token set — tools and context
should follow the user's attention (what page they're on, what they're
doing), not ship as one undifferentiated blob.

## Cache-breakpoint budget (hard invariant for the whole series)

The API allows 4 `cache_control` breakpoints. After v1.9.0 the budget is
**fully spent**: tools prefix (1) + promoted segment (1, promoting pages
only) + system primer (1) + incremental message stamp (1). v1.9.2 *moves*
the system breakpoint (last block → primer block); it must not add one.
Nothing in this series or after it may introduce a fifth. Documented in
`registry.py` and `anthropic_adapter.py`.

## Deliberately out of scope (mixd doesn't have these either)

- Server-side compaction (`compact_20260112`) — still gated on real
  transcripts showing the 50-message cap + tool-result clearing insufficient.
- Memory tool / cross-session persistence — stays in `unscheduled.md` with
  its injection-reinfection security note.
- Conversation persistence / server-side history; parallel tool dispatch;
  parallel subagent fan-out.
- Viewed-month JIT context — month selection is page-local `useState`, not
  URL state; lifting it is its own frontend project (candidate follow-up).

## Standing conventions for this series

- Every registry change keeps the parity contract green
  (`test_registry_parity.py`) — new invariants get named tests, cribbed from
  mixd's `test_registry_parity.py` where they exist.
- Prefix byte-stability is a tested invariant, not a convention: the cached
  tool prefix must be byte-identical across every `page` value including
  `None`.
- Every phase ends with the full quality gate
  (`uv run ruff check . --fix && uv run ruff format . && uv run basedpyright src/ && uv run vulture && uv run pytest`
  + `pnpm check && pnpm test`) and a live chat smoke test.
